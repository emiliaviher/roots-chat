# Roots-chatbotin prototyyppi

Klikattava prototyyppi Roots Helsingin (rootshki.fi) asiakaspalveluchatista.

- `index.html` on koko prototyyppi yhtenä tiedostona.
- Vastaukset on koottu rootshki.fi:n sisällöistä 17.9.2026.
- Tuntiajat ovat varausjärjestelmän tilannekuva 17.9.2026, ja jokainen aika vie suoraan kyseisen tunnin varaukseen.
- Tekoäly ei ole käytössä: botti tunnistaa kirjoitetuista kysymyksistä avainsanoja.

Sivun yläreunassa voi valita toimintatavan (A tai B) ja kokeilla chatin eri tiloja.
